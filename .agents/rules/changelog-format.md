# Discord Changelog Formatting Rule

When the user asks for a changelog, progress recap, or summary of updates for the band/Discord:
1. Format it using Discord markdown (bold `**`, bullet points `•`, clean sections, emojis).
2. Avoid raw local IDE file links (e.g. `file:///...`) or raw code paths that break/look ugly in Discord.
3. Write the changelog in **Swedish only** (tailored for easy reading by the band members). No English translation needed.
4. Structure clearly into "🎸 **Uppdatering av hemsidan — Senaste nytt!**", "✨ **Vad som är nytt:**", and "📋 **Nästa steg / Kvar att göra:**".
